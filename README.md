📌 ABOUT DocuMind AI is an AI-powered chatbot that allows users to upload PDF, TXT, and DOCX documents and ask questions about their content using Retrieval-Augmented Generation.

✨ FEATURES • Multiple document uploads • Automatic text extraction and chunking • Local Hugging Face embeddings • FAISS vector database • NVIDIA Nemotron AI responses • Context-based question answering • Chat and knowledge base management

🛠️ TECH STACK • Python • Streamlit • LangChain • NVIDIA Nemotron • Hugging Face Embeddings • FAISS

⚙️ INSTALLATION

Install dependencies: pip install -r requirements.txt
Create a .env file: NVIDIA_API_KEY=your_api_key
Run the application: streamlit run app.py

🚀 USAGE

Upload your documents.
Click Process Documents.
Ask questions about your documents.
Receive AI-generated answers.
